🛠️ 環境安裝與執行步驟詳細說明

1 準備 Python 執行環境 (System Requirements)

本工具基於 Python 非同步（asyncio）多執行緒架構設計。請確認您的電腦已安裝 Python 3.8 或更高版本（推薦使用 Python 3.10+ 以獲得最佳網路執行效能）。您可以在控制台或終端機輸入 python --version 來進行檢查。

2 安裝微軟 Edge-TTS 類神經語音套件

開啟命令提示字元 (CMD)、PowerShell (Windows) 或 Terminal (macOS/Linux)，執行以下 pip 指令以安裝微軟的語音合成引擎依賴套件：

pip install edge-tts
3 放置腳本檔案至同一個目錄

請將下載的 generate_tts.py（生成主程式）與 tts_scripts.txt（文字腳本檔）放置於本機同一個資料夾中。主程式在執行時會自動搜尋並載入同目錄下的 tts_scripts.txt。

4 執行語音批量生成

使用終端機進入放置上述兩檔案的資料夾，支援以下兩種靈活的指令模式：

💡 模式 A：一鍵批量生成全部 20 段音檔 讀取腳本內容，同時生成 01 到 20 號所有高品質 MP3 檔案：
python generate_tts.py
⚡ 模式 B：指定特定編號單獨更新 / 生成 若您只修改了腳本中的特定段落，可輸入數字單獨重新生成該段：
python generate_tts.py 11
5 自訂與微動態調整 (Customization)

• 修改台詞：使用文字編輯器（如記事本、VS Code）打開 tts_scripts.txt，直接修改對應編號底下的台詞文字並儲存，然後重新執行模式 A 或 B 即刻更新！
• 調整編碼（避雷指南）：Windows 系統命令提示字元預設使用 Big5 (CP950) 編碼，在顯示或解析 UTF-8 的特殊符號（例如表情符號）時，常會發生 UnicodeEncodeError 錯誤中斷。我們的主程式 generate_tts.py 內部已預先配置了自動編碼防禦機制。若在執行時控制台出現亂碼，建議可以在執行前先輸入 chcp 65001 指令切換控制台編碼至萬國碼 UTF-8 以確保 100% 完美執行！

🎧 台灣男女童音（HsiaoChen / YunJhe）聲學調校物理原理

這 20 種聲音中，我們透過控制語速 (Speech Rate) 與音調基頻 (Pitch) 的物理特徵，成功模擬了生理共鳴腔的變化：
• 女童聲與女幼童聲 (11-15 號)：使用台灣曉臻 (HsiaoChen)，音調拉高 +30Hz 至 +45Hz，物理性縮小共鳴腔，呈現稚嫩萌感的精緻童音。
